## 一、先分清：你缺的是账号，还是订阅

这两件事经常被混成一件，混了就会买错东西。

| 你以为在买 | 实际买到的 | 常见落差 |
|---|---|---|
| "Grok 会员" | 一个已注册账号的登录权 | 账号里没有订阅，进去还是免费层 |
| "带会员的账号" | 订阅期只剩几天的号，或共享池的一个席位 | 到期归零、或被人改密踢出 |
| "永久可用的号" | 批量注册号，售后期 7 天 | 第 8 天起掉号无人负责 |
| "开在我号上的会员" | 代充：订阅挂在你自己账号上 | 这个才是"买订阅"，不是"买账号" |

**判断口诀：账号是容器，订阅是容器里的东西。** 容器可以换（换绑、改密），里面的东西会到期。要长期用，容器必须是你自己的。

## 二、三条路径的硬指标对照

| 指标 | 自己注册 + 代充 | 自己注册 + 虚拟卡自付 | 买现成账号 |
|---|---|---|---|
| 前置条件 | 邮箱 + 海外网络 | 邮箱 + 海外网络 + 可用的国际卡 | 只需付款 |
| 账号归属 | 你的 | 你的 | 卖家的（只能换钥匙） |
| 能否换绑邮箱 | 本来就是你的 | 本来就是你的 | 看卖家配合度 |
| 订阅归属 | 你的账号 | 你的账号 | 可能挂在别人账号上 |
| 续费 | 找同一个卖家续，或换路径 | 自己续 | 换号续（等于重新买） |
| 掉档后谁负责 | 卖家按剩余天数折算 | 自己承担 | 7 天内补号，之后无 |
| 适合谁 | 长期主力 | 有卡、且愿意自己维护 | 一次性试玩、可丢弃 |

**一句话选路：断了会误事 → 走前两条；断了只是少个玩具 → 第三条随便。**

## 三、自注册清单（四步 + 三项前置）

- [ ] **前置 1：能长期收信的邮箱。** 不要公司邮箱、不要一次性邮箱；这个邮箱就是账号的钥匙；
- [ ] **前置 2：稳定的海外网络。** X 与 grok.com 国内直连都不通，这一项不满足，后面全白费；
- [ ] **前置 3：可用的手机号。** 部分验证环节要接码，接码平台的号段复用率高，容易被判异常；
- [ ] **步骤 1：注册。** X 侧用邮箱或手机号 + 用户名；grok.com 侧可用 X 授权登录，也可用邮箱单独注册 xAI 账号；
- [ ] **步骤 2：完成验证。** 邮箱验证码 / 手机验证，一步都不要跳；跳过验证的号在订订阅时最容易被拦；
- [ ] **步骤 3：先当免费用户跑两天。** 登录、发几条对话、传一张图，留下正常使用记录；
- [ ] **步骤 4：再开订阅。** 新注册 + 立刻跨区付款是风控最敏感的组合，隔两天成功率明显更高。

> 两个常见误判：**能登录 ≠ 功能全开**（新功能按市场分批开放）；**能注册 ≠ 能付款**（订阅走应用内购买或国际卡，国内卡不在列表里）。

## 四、买号前的十项验号清单

按这张表问，答不上来的项越多，风险越高。带 ★ 的是必须项。

| # | 检查项 | 怎么查 | 不合格信号 |
|---|---|---|---|
| 1 ★ | 注册时间 | 让卖家截账号设置页的注册日期 | 注册于 7 天内 → 与你自己注册无异，没必要买 |
| 2 ★ | 能否改绑邮箱 | 明确问"改绑走什么流程、要不要原邮箱验证" | 只说"可以改"但说不出流程 |
| 3 ★ | 掉号怎么处理 | 要一句可执行的话：补号 / 退款 / 折天数 | 只答"放心用" |
| 4 | 是否有历史内容 | 看对话、关注、发帖痕迹 | 一片空白却自称老号 |
| 5 | 能否无限供货 | 问"还有几个同款" | 能给出十个以上 → 批量注册 |
| 6 | 是否允许先登录后付款 | 要求屏幕共享或远程看一次 | 只发截图、付款后才给凭证 |
| 7 | 登录设备数 | 到手后看安全页的设备 / 会话列表 | 有陌生设备且踢不掉 |
| 8 | 订阅状态与到期日 | 看档位名 + 下一个扣款日 + 计费地区 | 三项有一项对不上 |
| 9 | 订阅来源 | 问"这个订阅是怎么开的" | 答不出，或回避"共享"两个字 |
| 10 | 争议处理方式 | 问"出问题走平台还是私下" | 只肯私下转账 |

**第 7 项最值得停一下：** 踢不掉陌生设备，或踢掉后又被加回来，说明这号是共享的——不是"可能共享"，是"确定共享"，直接终止。

## 五、账号"过户"到底能不能成

| 把手 | 能不能动 | 备注 |
|---|---|---|
| 密码 | 能，且必须立刻改 | 独立密码，不与任何现有账号复用 |
| 邮箱 | 多数能改 | 需要原邮箱配合验证，或等冷却期；买家改不了就等于钥匙还在卖家手里 |
| 手机号 / 两步验证 | 看账号状态 | 至少加一个自己的两步验证方式 |
| 注册时间 / 注册地区 | **改不了** | 风控判定的第一层依据 |
| 历史登录 IP | **改不了** | 多国 IP 记录会一直留着 |
| 绑过的第三方 | **改不了** | OAuth 授权记录不会因换绑消失 |

**结论：能过户的是钥匙，不是房子。** 所以买号只能按消耗品对待——这句话不是态度问题，是结构问题。

## 六、"7 天号"的成本为什么这么低

| 成本项 | 量级 | 说明 |
|---|---|---|
| 注册 | 几元 / 个 | 接码号段 + 批量邮箱，摊薄后极低 |
| 订阅 | 0 | 多数 7 天号只有免费层 |
| 售后 | 再补一个号 | 补的是同批次号，边际成本接近零 |
| 长期责任 | 无 | 这才是低价的真实来源 |

三条推论，都能验证：

1. **"7 天"是售后期，不是使用寿命。** 卖家承诺的是七天内掉号补一个，第八天起与他无关；
2. **清理按批次，不按个人。** 批量号的特征是注册时间集中、邮箱域名雷同、IP 段重叠；同批里有人触发风控，整批一起掉。"我用了三天都好好的"不能证明安全，只能证明还没赶上处理时间；
3. **"长期 + 极低价格"必然有一个是假的。** 要么后面有追加成本，要么"长期"只到你发现问题为止。

## 七、到手后 60 分钟清单

- [ ] 0-5 分钟：登录，确认能进、能看到订阅页（卖家允许的话，付款前就做）；
- [ ] 5-10 分钟：改密码，独立密码；
- [ ] 10-20 分钟：换绑自己的邮箱（换不了就标记为"消耗品"，别放长期资料）；
- [ ] 20-30 分钟：开两步验证，用你自己的验证器或手机号；
- [ ] 30-40 分钟：安全页踢掉所有陌生设备与会话；
- [ ] 40-50 分钟：核对档位名、下一个扣款日、计费地区；
- [ ] 50-60 分钟：跑一次高消耗功能（视频生成、长上下文任务），确认额度真解锁。

任何一步对不上，先按 [充值没生效排查](troubleshooting-no-effect.md) 走一遍，再带订单号与截图找卖家。

## 八、五件不要做的事

| 动作 | 为什么不行 | 后果 |
|---|---|---|
| 绑自己的主邮箱 / 主手机号 | 号被判异常会连带验证通道 | 邮箱和号一起出问题 |
| 多人同时登录 | 多设备多地区在线是共享的最直接证据 | 整号一起掉 |
| 频繁切换节点国家 | 比"注册时间短"更容易触发风控 | 冷静期、订阅被清 |
| 在里面放 API 密钥 / 客户资料 | 号没了资料拿不回 | 密钥连着你的账单 |
| 把买来的号当主力 | 主力意味着断了会误事 | 出事时没有责任方 |

## 九、常见问答

**Q1：Grok 账号能自己注册吗？需要什么？**
能。两条路：X 账号（邮箱或手机号 + 用户名），或 grok.com 用邮箱单独注册 xAI 账号（也可用 X 授权登录）。需要能长期收信的邮箱、稳定的海外网络，部分环节要手机验证。

**Q2：买的号能改成自己的吗？**
密码能改、邮箱多数能换绑、两步验证看账号状态。但注册时间、注册地区、历史 IP、绑过的第三方改不了。所以只能算"拿到钥匙"，不能算"过户"。

**Q3：7 天账号是什么意思？**
卖家承诺 7 天售后的批量注册号：七天内掉号补一个，第八天起不负责。7 天是售后期，不是寿命。这类号多数只有免费层。

**Q4：买号便宜还是代充便宜？**
看你缺的是账号还是订阅。只要订阅、账号是自己的，代充更划算（开在自己号上、掉档按剩余天数折算）；要一次性可丢弃的身份，买号成本最低。两者不是同一个商品，比价前先比风险归属。

**Q5：代充要提供密码或验证码吗？**
不要。正规代充只要 X 用户名或邮箱，订阅开在客户自己的账号上。要密码、验证码、备份码的，一律终止交易——这是唯一不需要犹豫的一条。

**Q6：买来的号能续费吗？**
能，但续的是别人名下的账号。换绑不了邮箱时，续费等于继续把钱交给一个有钥匙的人；稳妥做法是把订阅迁到自己注册的账号上，或直接改走代充。
