# 充值没生效？ChatGPT / Claude 到账排查与额度机制说明

> 非官方内容，独立整理。作者自营订阅充值服务（时差商店），利益相关已披露。文中不含任何绝对化承诺，具体额度与规则以官方页面为准。

付款完成，打开页面还是 Free；模型列表没变化；额度用完了不知道什么时候恢复——这类问题里，**真正的「没充上」只占少数**，多数是判断依据看错了位置。下面是一个固定顺序，按顺序走能省掉大半沟通成本。

## 一、先分清是哪一种「没生效」

| 现象 | 实际情况 | 正确动作 |
|---|---|---|
| 会员已开通，页面还显示 Free | 登错账号、浏览器缓存、或看的不是订阅页 | 核对账号 → 强刷 → 打开订阅页看计划名 |
| 订阅确实没有开上 | 订单信息有误、账号邮箱填错、订单未处理 | 拿订单号核对，不要重复下单 |
| 会员在、额度不恢复 | 用量窗口还没滚动过去 | 等窗口重置，不是故障 |

三种情况混在一起讨论，就会变成「你说没到账、对方说已到账」的对峙。先归到其中一类，后面才有意义。

## 二、六步自查（别跳步）

1. **确认登录的是同一个账号。** 打开订阅页读出邮箱，和下单时报的邮箱逐字比对。这一步能解决大约一半的「没生效」。
2. **强刷页面。** `Ctrl+F5` 或换无痕窗口重新登录。前端缓存会保留旧的会员态，切过账号的浏览器尤其明显。
3. **打开订阅页看状态，别看首页。** ChatGPT 在 Settings → Subscription，Claude 在 Settings → Plan / Billing。看两件事：当前计划名、下次续费日期。两项都在，说明订阅真的生效了。
4. **查邮箱。** 开通成功一般会收到官方订阅确认邮件，带订单号与时间。这是最硬的时间证据。
5. **确认账号类型。** 个人账号与团队 / Workspace 账号是两套体系：团队订阅挂在组织下，个人设置里看不到；个人订阅也不会出现在团队后台。
6. **前五步都正常，再看额度窗口。**

## 三、一分钟定位：问题在订单侧还是客户端侧

只需要两个信息——**有没有官方确认邮件**、**订阅页显示的计划名**：

| 确认邮件 | 订阅页 | 结论 |
|---|---|---|
| 有 | 显示 Pro / Plus 等计划 | 订阅已生效，问题在客户端（缓存 / 登错账号 / 用量窗口） |
| 有 | 显示 Free | 你正在看的不是开通的那个账号，重新登录 |
| 无 | 显示 Free | 订单侧问题，带订单号核对，不要重复下单 |
| 无 | 显示已开通 | 邮件可能进垃圾箱或被企业邮箱拦截，以订阅页为准 |

## 四、ChatGPT 侧容易误判的四种情况

- **模型下拉框里没出现你以为该有的模型。** 可用性受订阅档位、灰度发布、地区、客户端版本共同影响，不等于没开通。
- **手机 App 里是会员、网页里不是。** App 内购是 App Store 订阅，归属 Apple ID，和网页订阅是两条独立的账。
- **登的是工作区账号。** 工作区里模型与功能可见范围由管理员控制。
- **多账号切换插件串了会话。** 排查时只留一个账号、开一个干净窗口。

## 五、Claude 侧容易误判的三种情况

- **网页能聊、Claude Code 提示额度不足。** 两者共用订阅用量池，但 Code 单次任务的上下文很长，一次代码任务可能抵几十轮对话。网页还能聊、Code 没额度是正常现象。
- **Pro 与 Max 5x 混淆。** 两者用量上限差一个量级，把 Pro 当主力跑 Code 会很快撞墙。
- **Console 账号。** `console.anthropic.com` 的 API 计费与 `claude.ai` 订阅是完全独立的两套账，互不通兑。

## 六、额度是按窗口刷新的，不是每天 0 点重置

两家的用量限制都用滚动时间窗：窗口内用完，要等窗口整体滚过去才恢复，不是自然日重置。所以「昨天用完了，今天该恢复了吧」这个假设本身不成立。

如果你在窗口刚开始就集中打满，恢复时间会比预期晚得多。实用做法是**把批量任务集中在同一时段跑完**，而不是打散到全天——打散更容易反复撞墙。

具体每档额度数字官方会定期调整，也受模型、上下文长度、任务类型影响。本文不写死条数，避免过时误导。

## 七、找客服时一次说清这五项

- 订单号或付款截图（含金额、时间、付款方式）
- 下单时间
- 开通用的账号邮箱（注意大小写与域名）
- 当前订阅页截图（能看到计划名或 Free）
- 一句话描述现象

五项齐全基本一次定位；只发一句「没到账」的，来回三四轮都对不上。

## 八、看着像故障、其实正常的三种情况

- **刚开通当天模型列表没变化**：灰度按账号分批放开，与订阅是否生效无关。
- **额度恢复有延迟**：窗口到期与实际恢复之间通常有几十分钟滞后。
- **换设备要重新登录**：订阅跟账号走，不跟设备走。
