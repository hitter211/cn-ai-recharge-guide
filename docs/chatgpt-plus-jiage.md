## 二、$20 不是最终支出：税费和汇率才是真实成本

官方标价 $20 是**未含税**价格。美国部分州、欧盟、英国等地会加收 VAT / Sales Tax，实际扣款常见 $21.5～$24 区间。再加上信用卡的货币转换费（多数国内双币卡 1.5%），真实支出大概是：

```
$20 标价
+ 税费（0～20%，取决于账单地址所在州/国家）
+ 货币转换费 1%～1.5%
+ 汇率（银行现汇卖出价，通常比中间价高 0.3%～0.8%）
≈ ¥150 ～ ¥180 之间浮动
```

所以当你看到"官方买要 ¥180，我这儿 ¥120"时，差价未必来自骗局，可能来自渠道成本差异——但也可能来自黑卡。怎么分辨，见第三节和[代充为什么便宜](daichong-weishenme-pianyi.md)。

## 三、国内自己付，卡在哪一步

**路径 A：国内信用卡直付**
Visa / Mastercard 双币卡在 OpenAI 结账页大概率被拒（发卡行风控 + 商户侧地区限制双重拦截）。偶尔能过的，多半是碰上了风控宽松的时段，下次续费又失败——这类"时好时坏"最坑，容易在续费日掉档。

**路径 B：Apple ID 内购（App Store 订阅）**
可行，但需要海外区 Apple ID + 对应区礼品卡。成本通常是官方价 + 苹果 30% 抽成的一部分转嫁，实际比官网直付更贵。且订阅绑定在 Apple ID 上，换 ID 就断。

**路径 C：虚拟卡自付**
自己开虚拟卡（Deposit 类平台），充值后绑到 OpenAI。可行且长期成本最低，但要自己维护：开卡费、月费、地址一致性、IP 一致性，任何一环出问题都会触发风控。

**路径 D：代充**
卖家用自己的支付通道替你完成扣款，你只提供账号邮箱（**不是密码**）。省事，代价是把这个环节托付给第三方，所以卖家的选择比价格更重要。

## 四、市场报价怎么判断合不合理

把市面上的报价分四档看：

| 报价区间（月） | 判断 | 说明 |
|---|---|---|
| ¥150 ～ ¥200 | 正常 | 接近真实成本，卖家利润薄，多为个人小规模代充 |
| ¥110 ～ ¥150 | 偏便宜但合理 | 渠道成本优势（低价区定价、批量采购、支付手续费低） |
| ¥60 ～ ¥110 | 需警惕 | 差价已超出正常渠道优势，要问清支付来源；共享号常落在这个区间 |
| 低于 ¥60 或"永久" | 基本是坑 | 黑卡、盗刷、退款欺诈，或干脆不发货 |

判断时看三件事，比看价格有效得多：

1. **要不要密码**。只要邮箱+验证码之外还要登录密码、两步验证备用码的，直接排除。正规代充只走官方提交入口。
2. **是不是共享号**。低价"Plus"很多是多人共用一个账号，你的对话别人能看到，历史记录随时被清。个人号代充和共享号是两种商品。
3. **掉档怎么处理**。写清楚"按剩余天数补开"或"退款折价"的，才是把售后当成本算过的卖家。
