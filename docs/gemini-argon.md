# Gemini Argon（氩）：首款模型退场时间线与使用验证清单

> 归档：Gemini 4 元素世代 · A1 簇。本文是仓库体（时间线对照 + 操作清单 + 验证步骤），完整论述版见文末官网对应页。

## 一、30 秒结论

Argon（氩）是 Gemini 4 世代第一个发布的模型（9 月 30 日），也是第一个退场的：11 月 18 日 Neon 发布当天，Google 把订阅列表里的 Argon 静默替换成 Neon。**现在订阅里点不到它，只剩 API 在售**；已接 API 的程序可继续用，12 月 1 日起 API 价从促销 $2 / $10 涨回 $4 / $20。新选型直接看 Neon，不用回头看 Argon。对多数读者，真正要做的动作只有两个：订阅用户改用 Neon，API 存量用户按第五节核对计价与迁移节奏。

## 三、退场时间线（五步看完）

1. **9-30**：Argon 发布，订阅档位里有它，API 开放。
2. **10-28**：Carbon 发布，旗舰档登场，Argon 退居次席。
3. **11-12**：Hydrogen 发布，免费档入场，Argon 价格优势归零。
4. **11-18**：Neon 发布；**同日官方帮助页把订阅列表里的 Argon 换成 Neon**，无公告、无邮件、无 changelog 条目。
5. **12-1**：与 Carbon 一起恢复标准价 $4 / $20（促销 $2 / $10 只到 11-30）。

一句话：Argon 不是"下架"，是被同代更强的 Neon **替换**了。此后看到的任何"Argon 订阅攻略"，先看发布日期——11-18 之前写的有一半内容已失效。

## 五、API 使用验证步骤（存量与新增都适用）

1. **确认渠道**：Argon 只在 Google 官方 API 里，没有独立下载页、安装包、网页版入口。任何"Argon 专用客户端/直连版"都按套壳处理。
2. **确认计价**：核对官方定价页当前档——11 月内 $2 / $10（促销），12 月起 $4 / $20。账单对不上价就是渠道有问题。
3. **确认配额**：API 侧按 key 计量，与订阅档位无关；"Pro Argon 限额"是订阅时代的旧话题，现在无意义。
4. **回归对比**：存量迁移前，同一段提示词在 Neon 跑一遍，确认输出质量与结构化格式无回退再切换。
5. **不抢尾巴**：Neon 日常价 $3 / $15 低于 Argon 标准价 $4 / $20 且分数更高，迁移是纯收益，按发版节奏安排即可。

## 八、FAQ

1. **Argon 是被删了还是改名了？** 都不是。它还在 API 里，只是订阅档位被 Neon 取代；名字、规格、API 端点都没变。
2. **12 月 1 日之后 Argon API 会被停吗？** 官方没有弃用通知；按"随时可能调整"对待，存量程序做好迁移预案即可。
3. **Argon 和 Carbon 什么关系？** 同世代，Carbon 是定位更高的旗舰（仅 Ultra 订阅可用）；12 月起两者 API 同价，Argon 失去价格理由。
4. **Prometheus/Helium/Krypton 这些新名字可信吗？** Helium（氦）有代码线索但未官宣；Krypton 已被爆料者自己证伪。都别当真消息传。
5. **现在开通 Gemini 订阅还能指定用 Argon 吗？** 不能。任何渠道都做不到——档位由 Google 侧控制，Argon 已不在列表里。
6. **Argon 的 1M 上下文和别款不一样吗？** 一样。四款共用同一份约 1M tokens 窗口（输入/思考/输出共享），差异在思考档与单价，不在窗口大小。
7. **API 从 Argon 迁到 Neon 要改多少代码？** 起步只改模型名字符串：端点、鉴权、消息格式一致；再按第五节做回归对比与用量核算，确认无回退再切换。
