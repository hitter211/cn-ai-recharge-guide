## 一、30 秒对齐名字

| 你可能听过的名字 | 实际是什么 | 现在的状态 |
|---|---|---|
| Grok | xAI 的产品（App / 网页 / X 内入口），有免费层 | 一直在售，免费可用 |
| SuperGrok | 2026 年 10 月前 xAI 的付费订阅（$30/月） | 老订户保留，新用户买不到 |
| SuperGrok Heavy | 旧体系顶配档（$300/月） | 同上，仅老订户 |
| X Premium / Premium+ | X 平台会员，附带 Grok 额度（$8 / $40） | Premium 仍售；Premium+ 已并入新套餐 |
| The X Subscription | 2026-10-12 起的统一订阅（Grok + Cursor + X 权益） | 新用户只有这条路 |

**一句话对应关系：旧 SuperGrok ≈ 新 Premium（$30）；旧 Heavy ≈ 新 Ultra（$200，档位不完全等价，按额度看）。**

## 二、现行五档速查

| 档位 | 月付 | 年付折合 | 用量 | 有无视频 | 有无 Grok Bot |
|---|---|---|---|---|---|
| Free | $0 | — | 有限 | 无 | 无 |
| Plus | $8 | 约 $7 | 1 倍（基准） | 无 | 无 |
| Premium | $30 | 约 $25 | 4 倍 | 有 | 有 |

三条使用规则：

1. **额度按倍数给，不给条数。** 一个池子供给对话、图片、语音、Build 和 Cursor 里的 Grok 模型，每周重置；
2. **分辨率是硬门槛。** 要 1080p 得 Super 及以上，Premium 档的视频规格低于它；
3. **API 是另一张账单。** 订阅含 API 访问权限，调用按 token 另计（旗舰模型每百万输入 $2、输出 $6，缓存输入 $0.5）。

## 三、三步选档（照着勾就行）

- [ ] **第一步：过去两周你打开过 Grok 几次？** 少于 5 次 → 停在免费层，别买；
- [ ] **第二步：你需要视频、Expert 模式、常驻 Bot 吗？** 都不需要 → Plus $8；至少需要一个 → Premium $30；
- [ ] **第三步：你现在是否同时付着 Cursor Pro 和 X Premium+？** 是 → $30 是净省钱，直接上；不是 → 先按月付，跑满一个计费周期看 Settings → Usage 的产品消耗分布，再决定要不要升 Super。

补一条反向判断：**连续两个月都撞额度 = 档位选低了；从来没撞过 = 选高了。** 这条只在你自己的账户里成立，任何评测都替代不了。

## 四、开通前必问的四句话（可直接复制）

1. 「**是开在我自己的 X 账号上，还是给我一个号？**」——开在自己号上，订阅归属清晰；给号的要问能否改密改绑、原持有人是否会找回；
2. 「**需要我提供什么？**」——只需要 X 用户名或邮箱。要密码、要验证码、要备用码的，到此为止；
3. 「**掉档怎么处理、几个工作日响应？**」——要"补开还是按剩余天数折算"的明确答复，口头承诺不算；
4. 「**这个价是 Plus 还是 Premium？**」——名字必须对得上档位。报价不说档位名的，一律要求补充。

顺手记一条现实：**官方条款写明订阅由官方直营、不授权第三方经销。** 因此"官方授权代理""中国区总代"这类身份不存在，看到就当减分信号。第三方开通的本质是代付或整号交付，能稳多久取决于渠道干净程度和卖家的质保条款。

## 五、付款后验号清单（两分钟）

- [ ] **登对账号**：Grok 与 X 常用不同邮箱，先确认登录的是开通时给的那个；
- [ ] **看档位名**：账户 → 订阅页显示 Plus / Premium / Super / Ultra，名字必须与下单时一致；
- [ ] **看到期日**：按付款成功日起算一个月，不是自然月；日期偏短说明是短周期号或共享位；
- [ ] **跑一次高消耗功能**：生成一段视频或用一次 Expert 模式，能跑通才算真解锁；
- [ ] **看 Usage**：Settings → Usage 里的百分比、产品分布与重置时间，是唯一准的余量口径。

四步里有任何一步对不上，先按 [充值没生效排查](troubleshooting-no-effect.md) 走一遍，再带订单号与截图找卖家。

## 六、六个容易被坑的点

| 坑 | 表现 | 怎么避 |
|---|---|---|
| 旧文章当现价 | 引用「SuperGrok $30」却按 $8 卖你 Plus | 报价必须说档位名，不说的不买 |
| 「高级版模型」话术 | 暗示 SuperGrok 是更聪明的模型 | 模型同一代，付费买的是额度与功能 |
| 混淆内购价与网页价 | 拿 App 内高价当"官方涨价" | 只认结账页当期显示 |
| 年付锁死错档 | 一上来买年付，用两周发现不对 | 先按月，跑满一个周期再年付 |
| 共享位伪装独享 | 便宜、到期日偏短、常被踢 | 看到期日与是否可改密 |
| 频繁换节点 | 开通后多国 IP 登录被判异常 | 固定一两个出口，不开通后立刻换环境 |

另外两条与钱无关但更贵：**不要给验证码备用码**（等同账号钥匙），**不要多人共用一个付费号存敏感内容**。

## 七、老订户要不要切换

手上还留着 SuperGrok / Heavy / Cursor 旧套餐的人，官方明确说**切换是可选的，不切原套餐继续有效**。要不要动，按三条判断：

- [ ] **算总账**：旧套餐如果是 SuperGrok $30 + Cursor Pro $20 + X Premium+ $40，合计 $90；换成 Premium $30 就是净省，值得切；
- [ ] **看不可逆性**：切过去旧方案会被取消并按比例退款，**切了不能切回来**。功能上有依赖（例如某个旧档才有的额度包）就先别动；
- [ ] **查 App Store 订阅**：在 iPhone / Android 内购买的 Cursor 旧订阅不会因网页端切换而自动取消，**必须自己去系统订阅设置里关掉**，否则 Apple / Google 会继续扣款——这是迁移里最常见的一笔冤枉钱。
