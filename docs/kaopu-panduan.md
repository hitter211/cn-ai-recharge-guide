# 代充服务商可信度评分卡：12 项自查、话术词典与纠纷处理时间线（2026-11）

> 本文是 [主教程](../README.md) 的补充篇，更新于 **2026 年 11 月 23 日**。作者自营订阅充值服务（时差商店），利益相关已披露，非官方，与 OpenAI / Anthropic / Google / xAI 无隶属或授权关系。
>
> 这一篇只解决一个动作：**在付钱之前，用 3 分钟给一家代充打分，然后决定买不买。** 不讲道理，只给可勾选的清单、可对照的话术和出事后的处理顺序。价格与政策以官方页面当天显示为准。

## 一、怎么用这张卡

三个步骤，不需要任何专业知识：

1. 打开卖家的店铺页或聊天窗口，把下面 12 项挨个问一遍（大部分在对方主页、商品描述、客服答复里就有）；
2. 每项按 **0 / 1 / 2** 打分（0 = 答不上来或回避，1 = 口头说得清但拿不出凭证，2 = 有文字、有入口、可复查）；
3. 加总分，对照分档结论，再决定下不下单。

**分数不是"好卖家认证"，只是把"感觉还行"换成"能指出哪几项不行"。** 任何一项 0 分，都建议直接换一家，不必纠结总分。

## 二、12 项评分表

| # | 检查项 | 2 分（合格） | 1 分（含糊） | 0 分（危险） |
|---|---|---|---|---|
| 1 | 账号归属 | 明确写"开在你自己账号上" | 说"都可以"，看套餐 | 只卖现成号、不给选 |
| 2 | 需要的凭据 | 只要会话凭证或 Org ID（Gemini 只要 Gmail） | 说不清要什么 | 要密码、验证码、备用码 |
| 3 | 订单可查 | 有订单号 + 固定查询页面 | 只有聊天记录 | 付完只能靠微信追问 |
| 4 | 时效承诺 | 写明时段与上限（如工作时段 2 小时内） | 只说"尽快" | 不给任何时间 |
| 5 | 质保条款 | 写明期限 + 折算方式 + 执行人 | 说"包赔"但无细则 | "永久质保"却问不出怎么执行 |
| 6 | 售后入口 | 店铺/企业微信等可追溯主体 | 只有一个个人微信号 | 收款码与客服不是同一人 |
| 7 | 能否开票 | 明确能开企业增普票 | 说"可以想想办法" | 直接说不能、或反问为什么 |
| 8 | 凭证失效 | 承诺开通后立即作废/删除 | 说"我们会保管好" | 要求长期保留你的凭证 |
| 9 | 报价与档位对应 | 报价写清产品 + 档位 + 周期 | 只给一个数字 | 用"高级版""至尊版"代替档位 |
| 10 | 价格合理性 | 落在公开市场区间内 | 略低于区间下沿 | 低到不可能（见第五节） |
| 11 | 支付方式 | 有担保交易或对公收款 | 私人收款但订单可查 | 只收虚拟币、只收红包 |
| 12 | 售后话术 | 承认"可能掉档，掉了怎么赔" | 回避失败情形 | 说"绝对不会掉、掉了不可能" |

**分档结论：**

- **18-24 分**：可以下单。仍然按第六节验号，验完再确认收货；
- **12-17 分**：能买，但只买最短周期（1 个月），别一次买年付；
- **12 分以下**：换一家。不用试图"多问几句把他问明白"，问不明白本身就是答案。

## 三、话术词典：12 句常见说法，翻译成可验证的动作

| 卖家说 | 实际含义 | 你该追问 |
|---|---|---|
| "官方内部渠道 / 员工折扣" | 官方不对第三方开内部折扣，这是包装 | "能给我订单号或官方扣款凭证吗？" |
| "我们是官方授权代理" | 主流厂商条款写明订阅直营、不授权经销 | "授权文件在哪一页？"（答不出即减分） |
| "永久质保，掉了包赔" | 没有期限、没有折算、没有执行入口 | "按剩余天数折算还是换号？几天内处理？" |
| "全网最低价" | 成本结构决定不可能长期成立 | "这个价对应哪个档位、哪个周期？" |
| "秒开，不用给任何信息" | 要么是成品号，要么根本没开在你号上 | "不开在我号上，那订阅挂在哪？" |
| "先把密码给我，我帮你操作" | 等同于交出账号控制权 | 结束对话，不要解释 |
| "验证码发我一下，马上就好" | 同上，验证码是登录钥匙 | 结束对话 |
| "这是企业版共享位，比独享便宜" | 共享位，会被踢、会被清 | "同时几个人在用？" |
| "最近平台风控，需要等 24 小时" | 可能真，也可能是拖延话术 | "订单号给我，我自己去查状态" |
| "掉档是官方问题，跟我们无关" | 责任推给上游，等于没有质保 | "那你们的质保条款覆盖什么？" |
| "先确认收货，我再给你开" | 把风险全部前置给你 | 拒绝，或走担保交易 |
| "老客户都这样买的，你放心" | 用群体背书替代条款 | "给我看一条写明的售后规则" |

记一条规律：**凡是"身份型"话术（授权、内部、总代），一律无法验证；凡是"条款型"话术（几天、怎么赔、找谁），一律可以验证。** 只信后者。

## 四、按产品看凭据：给什么、不给什么

不同产品的开通环节不一样，需要的凭据也不同。给多了是风险，给少了办不成：

| 产品 | 正规流程需要的 | 绝对不给 | 到账后自己看哪里 |
|---|---|---|---|
| ChatGPT | 会话凭证（access token）或邀请方式 | 密码、邮箱验证码、备用码 | 设置 → 订阅，看档位与到期日 |
| Claude | Organization ID 或邀请方式 | 密码、登录验证码 | Settings → Billing / Plan |
| Gemini | 一个可登录的 Gmail 地址 | Google 密码、两步验证码、备用码 | one.google.com 订阅页 |
| Grok / X | X 用户名或绑定邮箱 | 密码、备用码 | grok.com 账户页 → 订阅 |
| Muse（Meta） | 账号邮箱或 tokens 套餐确认 | 密码、支付密码 | 应用内订阅/额度页 |

三条通用规则：

- **只要"能定位到你账号"的信息，不要"能登录你账号"的信息。** 前者是邮箱、ID、用户名；后者是密码、验证码、备用码。
- **会话凭证也有寿命。** 正规做法是开通完成后立刻让它失效（改密码或退出全部会话），并让卖家确认已删除。
- **任何要身份证、银行卡、实名的"代充"，性质已经变了**，不是代充，是借你的身份做别的事，直接停止。

## 五、报价合理性：三档区间怎么看

价格是最快的筛子，但要按"官方价 → 市场区间 → 红线"三层看，不能只看绝对值。下表的官方价是 2026 年 11 月核对值：

| 产品 | 官方定价 | 市场常见区间（人民币/月） | 红线（低到这个程度必有代价） |
|---|---|---|---|
| ChatGPT Plus | $20/月 | ¥120-190 | 低于 ¥100 |
| ChatGPT Pro | $100 起/月 | ¥680-780 | 低于 ¥500 |
| Claude Pro | $20/月 | ¥135-170 | 低于 ¥100 |
| Claude Max | $100 / $200 月 | 按档位报，通常 ¥700 起 | 低于官方价三成 |
| Gemini AI Pro | $19.99/月 | 围绕官方价小幅浮动 | 低于 ¥90 |
| Grok Plus | $8/月 | 本站 ¥50（1 个月） | 低于 ¥25 |
| Muse AI | 按 tokens 计 | 本站 310 亿 tokens ¥15 | 报价不说 tokens 量 |

看这张表的方法只有一句：**低价不是问题，"低到不可能"才是问题。** 便宜 5%-20% 属于正常竞争（渠道成本差异），便宜一半以上一定是别的东西在补贴——共享位、活动资格转移、来源不干净的支付通道，或者根本不会交付。

另外注意两件事：一是**报价必须带档位名**，只说"会员"不说 Plus/Premium/Ultra 的，先要求补充；二是**年付要按"卖家能不能活一年"折算**，年付便宜 20% 但服务商三个月后消失，实际成本是 100%。

## 六、验号五步（通用），两分钟做完

付款后不要只看截图。自己登进去，按顺序看五处：

- [ ] **第一步：登对账号。** 确认登录的是开通时给的那个邮箱/用户名。"没到账"里有相当一部分是登错了号；
- [ ] **第二步：看档位名。** 订阅页显示的档位必须与下单时一致。名字不对，立刻截图；
- [ ] **第三步：看到期日。** 按付款成功日起算一个周期，不是自然月。日期明显偏短 → 短周期号或共享位；
- [ ] **第四步：跑一次高消耗功能。** 视频生成、长上下文、高额度任务，能跑通才算真解锁；
- [ ] **第五步：看扣款来源与地区。** 计费地区、支付方式末四位应与卖家说明一致。地区对不上，说明订阅挂在别的账号或别的区。

任何一步对不上，先按 [充值没生效排查](troubleshooting-no-effect.md) 自查一轮，再带**订单号 + 订阅页截图 + 沟通记录**找卖家。只说"没到账"的沟通，处理速度会慢很多。

## 七、纠纷处理时间线：按小时走，不按情绪走

出问题时最耗人的不是损失，是不知道该做什么。按下面这条线走：

| 时间 | 该做什么 | 要留的证据 |
|---|---|---|
| 0-2 小时内 | 改密码、退出全部设备会话；确认订阅状态截图 | 订阅页截图、订单号 |
| 2-24 小时 | 走店铺/平台客服入口（不是个人微信）；提出明确诉求：补开或按剩余天数折算退款 | 聊天记录、客服承诺原文 |
| 24-72 小时 | 无回应则升级：平台投诉入口、支付渠道争议 | 全部沟通时间线 |
| 3-7 天 | 公开评价区留事实描述（不带情绪、只写时间与结果） | 事实清单 |
| 超过 7 天 | 止损，不再追加付款；把这次经历当作筛选成本 | — |

两条经验：**一是所有承诺都要落到文字**，语音和电话在纠纷里等于没发生；**二是不要把"公开曝光"当第一手段**，先走客服和平台入口，成功率反而更高。
