## 二、五分钟自测：你到底缺不缺这一档

按顺序勾，勾到第一条"是"就停，答案就是那一档：

- [ ] **过去两周我打开它不到 5 次** → 停在免费层，别买；
- [ ] **我每天用一两小时，主要是写作、问答、翻译，偶尔改代码** → Plus，够了；
- [ ] **我一周里有三次以上因为额度用完被迫中断** → 该升 Pro；
- [ ] **我每天在里面连续待三小时以上，或长任务要挂着跑** → 直接 Pro，不要用 Plus 反复试；
- [ ] **我给团队/客户交付，多人共用一个号** → 先停。共用单号在风控眼里是异常信号，正确做法是按人开号。

反向判断同样有效：**连续两个月都没撞过额度 = 档位买高了；一个月撞了五次以上 = 买低了。** 这条只在你自己账户里成立，任何评测都替代不了。

## 三、升档与降档的操作顺序

代充按月下单，走的是"新周期起算"，不是按天折算。所以顺序比价格更重要：

1. **到期前 3 天做决定**，不要等到期当天。卡点升档最容易出现"旧档已断、新档未生效"的空窗；
2. **确认登录的是同一个账号**。多账号是最常见的乌龙——钱花在 A 号、你天天登的是 B 号；
3. **先说清目标档位名**（Plus 还是 Pro 5x），报价里不带档位名的一律要求补充；
4. **升档按新周期起算**：月中从 Plus 升 Pro，Plus 未用完的天数通常不折钱，所以别在月中冲动升；
5. **降档不退差价**：已付 Pro 的月份降到 Plus 不会退差额，等下个周期再降更划算；
6. **尽量在同一账号续**。换号 = 聊天记录、Projects、自定义指令全丢，重配的时间成本通常超过省下的几十块。

## 四、升完怎么验：五步验号（防"名义升档"）

付款之后最常见的困惑是"我明明买了，怎么还是免费版"。按这个顺序查，五步内能定位：

| 步骤 | 查什么 | 判定 |
|---|---|---|
| 1 | 当前登录的账号是不是下单那个 | 邮箱/用户名对不上 → 钱花在另一个号上了 |
| 2 | 设置里的订阅页显示的套餐名 | 显示 Free → 未生效；显示 Plus/Pro → 已生效 |
| 3 | 客户端是否需要退出重登 | 网页生效但客户端没变 → 退出重登即可 |
| 4 | 账单/订阅记录里有没有本期扣费 | 有记录但仍是 Free → 找卖家按订单号核 |
| 5 | 高峰期是否还被限流 | 仍被限流 → 档位可能只升了名义，要求出示档位凭证 |

**判断"真升档"的唯一硬标准是第 2 步的套餐名，不是卖家的口头确认，也不是聊天窗口里的"已开通"。** 完整排查路径见 [充值没生效？到账排查](troubleshooting-no-effect.md)。

## 五、额度怎么读，别靠感觉

- **官方不给固定条数**，给的是"相对额度"。任何写死"每天 XX 条"的文章，写的时候就已经过时了；
- **看账号内的用量提示**，而不是第三方教程。额度按模型与功能分别计算，Codex、深度研究、图片生成各有各的池子；
- **长任务比对话吃得多**。同一个问题问十遍，不如一次让它读完十份文档——后者消耗常常是前者的数倍；
- **周维度看趋势**。连续一两周在周三就见底，说明档位确实不够；只在月末紧一次，属于正常波动。

## 七、常见问题

**Plus 和 Pro 的模型不一样吗？**
同一批。差别在次数上限、连续跑长任务的能力，以及高峰期的排队优先级。

**买 Plus 还需要单独买 API 吗？**
只在你要写脚本调用时才需要。网页和客户端使用不需要，订阅不含 API 额度。

**月中升 Pro，Plus 剩下的天数会退吗？**
通常不退，按新周期起算。所以升档时机放在到期前 3 天最省。

**Pro 5x 的"5x"指什么？**
指额度倍率，相对基准档的倍数，不是"五倍速度"。倍率越高，能连续跑的任务越多。

**升级后客户端还是免费版？**
先退出重登，再核对订阅页套餐名。三步都正常仍显示 Free，查订单是否开在了另一个账号上。

**年付更便宜吗？**
代充多为按自然月下单，长周期预付可能拿到小幅优惠，但建议先按月试一次，确认到账时效与售后条款之后再考虑。
